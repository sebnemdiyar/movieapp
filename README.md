## MovieApp
MovieApp, kullanıcıların filmleri keşfetmesini, film içeriklerini incelemesini ve sinema dünyasını kolayca takip etmesini sağlayan modern bir web uygulamasıdır. Kullanıcı dostu arayüzü ve responsive tasarımıyla keyifli bir film keşif deneyimi sunar.

## Özellikler

* Filmleri listeleme ve keşfetme
* Film detaylarını görüntüleme
* Kategoriye göre film keşfetme
* Modern ve kullanıcı dostu arayüz
* Açık ve koyu tema desteği
* Responsive tasarım

## Kullanılan Teknolojiler
* Next.js
* React
* React Router DOM
* React Icons
* Next Themes
* Tailwind CSS
